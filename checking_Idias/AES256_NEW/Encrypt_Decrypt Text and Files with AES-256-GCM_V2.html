AES-256-GCM Encryption / Decryption — V2

Security specifications

  • AES-256-GCM — authenticated encryption (AEAD)
  • PBKDF2-SHA-256 / 600 000 iterations — key derivation (OWASP 2023)
  • 32-byte random salt + 12-byte random nonce per operation
  • Web Crypto API — native browser crypto, constant-time GCM tag check
  • Files saved as pure binary — no Base64 inflation (+0 % vs +33 % in V1)
⚠ V2 encrypted files are not compatible with V1.
⚠ PBKDF2 with 600 000 iterations takes ≈0.5–2 s — the progress bar shows activity.
